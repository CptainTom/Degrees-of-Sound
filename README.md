# 🌍 Degrees of Sound

**Ακούς πώς άλλαξε η θερμοκρασία της Γης από το 1881 έως το 2023**, με δεδομένα της NASA.
Φτιαγμένο πρώτα απ' όλα για **τυφλούς και άτομα με χαμηλή όραση**.

## Πώς το τρέχουμε
1. Ανοίγουμε τον φάκελο του project στο **VS Code**.
2. Δεξί κλικ στο `index.html` → **Open with Live Server** (χρειάζεται internet για τον ήχο και τη 3D Γη).
3. ❌ **Όχι** διπλό κλικ στο αρχείο. ✅ Για τους κριτές: **GitHub Pages**.

## Η αρχική οθόνη: δύο τρόποι (modes)
| Mode | Για ποιον | Τι αλλάζει |
|---|---|---|
| **Listening mode** (προεπιλογή) | Τυφλοί / χαμηλή όραση | Ο **αφηγητής** (φωνή στα αγγλικά) εξηγεί τα πάντα. Όλα με το **πληκτρολόγιο**. |
| **Visual mode** | Όσοι βλέπουν | Χωρίς αφηγητή, η μουσική ακολουθεί αμέσως το ποντίκι. Οι screen readers ακούνε ακόμα τα πάντα. |

Το mode αλλάζει και μέσα από το **Menu (M)**. Υπάρχει χώρος για τρίτο mode.

## Τι ακούμε
| Ήχος | Τι σημαίνει |
|---|---|
| **Μελωδία του σημείου** (S για on/off) | Ψηλότερη **και** γρηγορότερη = πιο ζεστό από το κανονικό. Χαμηλότερη και πιο αργή = πιο κρύο. |
| **Όργανο** | Ζέστη = απαλή καμπάνα, κρύο = ξύλινο (μαρίμπα) |
| **Χαμηλό βουητό** | Ο μέσος όρος του πλανήτη εκείνη τη χρονιά |
| **Enter** | Όλη η γραμμή Βορράς → Νότος σαν άρπα (πρώτα η Αρκτική) |
| Ειδικοί ήχοι | καμπανάκι = ισημερινός · χαμηλό «μπουμ» = άκρη (πόλος, πρώτη/τελευταία χρονιά) · «ανάσα» = δεν υπάρχουν δεδομένα · απαλοί ήχοι στα μενού |

## Πλήκτρα
| Πλήκτρο | Τι κάνει |
|---|---|
| Βελάκια | Κίνηση (10°, με Shift 2°) |
| **, .** | Χρονιά πίσω / μπροστά (Shift: 10 χρόνια) · Home / End: 1881 / 2023 |
| **S** ή **Space** | Μουσική on / off |
| **Enter** | Παίξε όλη τη γραμμή Βορράς → Νότος |
| **M** | Menu (ρυθμίσεις), σαν μενού βιντεοπαιχνιδιού: ↑↓ κίνηση, ←→ αλλαγή, Enter, Esc |
| **H** ή **?** | Βοήθεια: κάθε πλήκτρο εξηγημένο με φωνή · Enter = δοκίμασέ το |
| **V** | Αφηγητής on / off (για όσους έχουν δικό τους screen reader) |
| **W** | «Πού είμαι;» |
| **T** | Ιστορία του σημείου: 1881 → 2023 ως μελωδία + περίληψη |
| **C** | Σύγκριση με το 1951 |
| **L** | Ξενάγηση στους ήχους (1 λεπτό) |
| **R** / Shift+R · **G** | Ραντάρ: πιο ζεστό / κρύο σημείο κοντά · G = πήγαινε εκεί |
| **N** | Κοντινά μέρη |
| **/** | Αναζήτηση (χώρες, περιοχές, ωκεανοί, π.χ. «Arctic») |
| **+ −** | Zoom |
| **D** | Κατέβασε τα δεδομένα του σημείου (CSV) |
| **Esc** | Σταμάτα την ομιλία / κλείσε μενού |

## Το Menu (M)
Mode · αφηγητής on/off · ταχύτητα φωνής · σύντομες/αναλυτικές περιγραφές · υπότιτλοι · ένταση · βουητό · ρυθμός (μπάσο/τύμπανα) · ταχύτητα γραμμής · explore by touch · **readable font** (για χαμηλή όραση) · μεγαλύτερα γράμματα · πίσω στην αρχική οθόνη.
Οι ρυθμίσεις αποθηκεύονται στον υπολογιστή.

## Δεδομένα
NASA SVS #5207 (GISTEMP v4), διαφορά από τον μέσο όρο 1951–1980. Όρια: τιμές μέχρι **±2 °C** (το +2 σημαίνει «+2 ή περισσότερο»), και το γκρι «χωρίς δεδομένα» μοιάζει με το λευκό «κανονικό», οπότε μετράνε και τα δύο ως 0.
